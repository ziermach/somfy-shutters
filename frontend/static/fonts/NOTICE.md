# Bundled fonts

These files are here because the app must work with no internet (constitution,
principle IV). Loading them from a CDN would break the house exactly when the
line goes down.

Both families are licensed under the SIL Open Font License 1.1, which permits
bundling and redistribution.

| File | Family | Source |
|---|---|---|
| `BricolageGrotesque-SemiBold.woff2` | Bricolage Grotesque | https://github.com/ateliertriay/bricolage |
| `IBMPlexSans-Regular.woff2` | IBM Plex Sans | https://github.com/IBM/plex |
| `IBMPlexSans-SemiBold.woff2` | IBM Plex Sans | https://github.com/IBM/plex |
| `IBMPlexMono-Medium.woff2` | IBM Plex Mono | https://github.com/IBM/plex |

Latin subsets only, as served by Google Fonts. Full license text:
https://openfontlicense.org
